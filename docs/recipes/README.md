# Recipes

Small, repeatable tasks with the list of files and a ready prompt for a
coding agent. One recipe = one pull request = one fresh agent session.

| Recipe | Code? |
|---|---|
| [Add a psychological mode (prompt)](add-mode.md) | usually none |
| [Change interface text](change-ui-text.md) | small |
| [Add a questionnaire with scoring](add-questionnaire.md) | yes, with a reference test |
| [Add a field to the admin panel](add-admin-field.md) | yes: migration + API + UI |

Before any recipe: read [AGENTS.md](../../AGENTS.md); finish with a green
`make check` and the pull request template.

рецепт написан на английском и русском.
