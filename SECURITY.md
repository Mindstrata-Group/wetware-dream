# Security policy

## Reporting a vulnerability

Please **do not** open a public issue. Report privately through GitHub
Security Advisories: **Security → Report a vulnerability** in this
repository ([direct link](https://github.com/Mindstrata-Group/wetware-dream/security/advisories/new)).

Include what an attacker can do, the steps to reproduce, and the version or
commit. Use synthetic data only.

We confirm receipt within 3 working days, agree on a fix and a disclosure date
with you, and credit you in the advisory unless you prefer otherwise.

## Supported versions

Security fixes go to the latest release. Older releases get fixes only for
critical issues, at the maintainers' discretion.

## Scope

In scope: the code in this repository and the `deploy/` template. Out of
scope: a particular installation run by someone else (report to its
operator), and findings that need a compromised server or admin account.

---

**По-русски.** Уязвимости — только приватно, через GitHub Security Advisories
(Security → Report a vulnerability), не в публичных issue. Ответим в течение
3 рабочих дней и договоримся о сроках исправления и публикации.
